# 프롬프트 예시 모음

## 예시 1: 기본 회사 소개

```
notes/example-company-intro.md 파일 내용을 바탕으로 
회사 소개 프레젠테이션을 만들어줘.

요구사항:
- 슬라이드 수: 5장
- 디자인: 깔끔하고 전문적인 파란색 계열
- 각 슬라이드마다 적절한 아이콘이나 일러스트 추가
- 폰트: 큼직하고 읽기 쉬운 스타일

출력 파일명: company-intro.pptx
```

## 예시 2: 이미지 포함

```
다음 구성으로 제품 소개 자료를 만들어줘:

1. 표지: "우리 제품 소개" + images/logo.png
2. 문제점: notes/problem.md 내용 사용
3. 해결책: notes/solution.md + images/product-screenshot.png
4. 주요 기능: 3개 기능을 나열, 각각 아이콘과 함께
5. 가격: notes/pricing.md 내용을 표로 표현
6. 문의: 연락처 정보

스타일: 밝고 친근한 느낌, 주황색 포인트 컬러
출력: product-deck.pptx
```

## 예시 3: 학습 자료

```
교육용 프레젠테이션을 만들어줘:

주제: Python 프로그래밍 입문
슬라이드: 10장
내용: notes/python-basics.md 참고

구성:
- 제목 슬라이드
- 목차
- 각 개념마다 1~2장 (코드 예제 포함)
- 연습 문제 슬라이드
- 참고 자료

스타일: 교육적이고 명확한 디자인, 코드는 monospace 폰트
출력: python-tutorial.pptx
```

## 예시 4: 투자 유치 (Pitch Deck)

```
투자자 대상 피치덱을 만들어줘:

구성:
1. 커버: 회사명 + 태그라인
2. 문제: notes/problem.md
3. 솔루션: notes/solution.md + images/demo.png
4. 시장 규모: notes/market-size.md (차트로 표현)
5. 제품: images/product-features.png
6. 비즈니스 모델: notes/revenue.md
7. 경쟁사 분석: 표 형식
8. 팀: notes/team.md + 팀원 사진들
9. 트랙션: 성장 그래프
10. 투자 요청: 금액 및 용도

스타일: 전문적이고 임팩트 있는 디자인, 어두운 배경 + 밝은 텍스트
출력: pitch-deck.pptx
```

## 프롬프트 작성 팁

### ✅ 좋은 프롬프트
- 구체적인 슬라이드 구성 명시
- 사용할 파일 경로 명확히 지정
- 원하는 디자인 스타일 설명
- 출력 파일명 지정

### ❌ 나쁜 프롬프트
- "프레젠테이션 만들어줘" (너무 막연함)
- 슬라이드 수나 내용 없이 요청
- 참고할 파일 지정 없음
- 스타일 선호도 미언급

### 💡 더 나은 결과를 위한 팁
1. 첫 시도에서 완벽을 기대하지 마세요
2. 결과를 보고 프롬프트를 수정해서 다시 시도
3. 너무 많은 슬라이드보다는 5~10장 정도가 적당
4. 색상, 폰트 등 구체적인 선호도를 명시하면 더 좋습니다
