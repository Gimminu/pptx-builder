# 무료로 AI 프레젠테이션 만들기

초보자를 위한 간단한 가이드입니다. 코딩 지식 없이도 AI를 활용해 파워포인트 파일을 자동으로 만들 수 있습니다.

## 이게 뭔가요?

여러분의 아이디어나 자료를 AI에게 알려주면, 자동으로 깔끔한 파워포인트 발표 자료를 만들어줍니다.

### 사용하는 도구들

- **Google Antigravity**: 구글에서 제공하는 무료 AI 서비스로, 텍스트를 이해하고 내용을 생성해줍니다
- **Node.js**: 컴퓨터에서 JavaScript 프로그램을 실행할 수 있게 해주는 프로그램입니다
- **Presentation Skill**: GitHub Copilot CLI의 기능으로, AI가 프레젠테이션 파일을 자동으로 만들어주는 도구입니다
- **Prompt**: AI에게 전달하는 명령어나 요청사항으로, 어떤 프레젠테이션을 만들고 싶은지 설명하는 글입니다

---

## 시작하기 전에 필요한 것

1. **컴퓨터** (Windows, Mac, Linux 모두 가능)
2. **인터넷 연결**
3. **Google 계정** (Antigravity 사용을 위해)
4. **GitHub Copilot CLI** (확인 필요: 설치 방법 확인 필요)

---

## 단계별 가이드

### 1단계: Node.js 설치하기

1. [Node.js 공식 홈페이지](https://nodejs.org/)에 접속합니다
2. "LTS" 버전을 다운로드합니다 (안정적인 버전)
3. 다운로드한 파일을 실행하고 설치합니다
4. 설치 완료 확인:
   - Windows: 시작 메뉴에서 "명령 프롬프트" 실행
   - Mac: Spotlight에서 "터미널" 실행
   - 아래 명령어를 입력하고 Enter:
   ```
   node --version
   ```
   버전 번호가 나오면 설치 성공!

### 2단계: 작업 폴더 만들기

1. 컴퓨터에서 원하는 위치에 새 폴더를 만듭니다
   - 예: `내문서/my-presentation` 또는 `Documents/my-presentation`
2. 이 폴더 안에 두 개의 하위 폴더를 만듭니다:
   ```
   my-presentation/
   ├── notes/          (여기에 발표 내용 메모 파일을 넣습니다)
   └── images/         (여기에 사용할 이미지를 넣습니다)
   ```

### 3단계: 자료 준비하기

**notes 폴더에 넣을 파일:**

- 발표 내용을 정리한 텍스트 파일 (`.txt` 또는 `.md`)
- 각 슬라이드에 들어갈 내용을 간단히 작성
- 예시:

  ```
  # 제목: 우리 회사 소개

  슬라이드 1: 회사 소개
  - 설립년도: 2020년
  - 직원 수: 50명

  슬라이드 2: 주요 제품
  - 제품 A: 모바일 앱
  - 제품 B: 웹 서비스
  ```

**images 폴더에 넣을 파일:**

- 발표에 사용할 이미지 파일 (`.jpg`, `.png` 등)
- 파일명은 영어나 숫자로 하는 것이 안전합니다
- 예: `company-logo.png`, `product-screenshot.jpg`

### 4단계: 터미널/명령 프롬프트 열기

1. **Windows 사용자:**
   - 작업 폴더에서 주소창을 클릭하고 `cmd` 입력 후 Enter
   - 또는 폴더 안에서 Shift + 오른쪽 클릭 → "여기서 PowerShell 열기"

2. **Mac 사용자:**
   - 터미널을 엽니다
   - `cd` 명령어로 폴더로 이동:
   ```
   cd ~/Documents/my-presentation
   ```

### 5단계: GitHub Copilot CLI 사용하기

(확인 필요: GitHub Copilot CLI 설치 및 인증 과정 필요)

명령어 예시:

```
github-copilot-cli
```

### 6단계: AI에게 프레젠테이션 만들기 요청

**프롬프트 예시:**

```
notes 폴더의 내용과 images 폴더의 이미지를 사용해서
프레젠테이션 파일을 만들어줘.

요구사항:
- 제목: [여기에 발표 제목 입력]
- 슬라이드 수: 10장
- 디자인: 깔끔하고 전문적인 스타일
- 이미지는 적절한 위치에 자동 배치

출력 파일명: presentation.pptx
```

**더 구체적인 예시:**

```
다음 내용으로 투자 유치 발표 자료를 만들어줘:

1. 표지: 회사명과 로고 (images/logo.png 사용)
2. 문제 정의: notes/problem.txt 내용 사용
3. 솔루션: notes/solution.txt 내용 사용, images/product.png 삽입
4. 시장 규모: notes/market.txt 내용을 차트로 표현
5. 팀 소개: notes/team.txt 내용 사용
6. 마무리: 연락처 정보

디자인: 파란색 계열, 최소한의 텍스트, 이미지 중심
출력: pitch-deck.pptx
```

### 7단계: 생성된 파일 열기

1. 작업 폴더로 돌아갑니다
2. 생성된 `.pptx` 파일을 찾습니다
3. 파일을 더블클릭해서 PowerPoint, Keynote, Google Slides 등으로 엽니다
4. 내용을 확인하고 필요한 부분을 수정합니다

## 주의할 점

⚠️ **무료 플랜 제한**

- Google Antigravity 무료 플랜은 하루 사용 횟수나 생성 가능한 슬라이드 수에 제한이 있을 수 있습니다
- 제한을 초과하면 다음 날까지 기다리거나 유료 플랜으로 업그레이드해야 합니다

⚠️ **출력 품질 차이**

- AI가 만든 결과물은 매번 조금씩 다를 수 있습니다
- 원하는 결과가 나오지 않으면 프롬프트를 더 구체적으로 수정해서 다시 시도해보세요
- 복잡한 디자인이나 특수한 레이아웃은 완벽하지 않을 수 있습니다

⚠️ **수동 편집 필요**

- AI가 만든 프레젠테이션은 초안(draft)으로 생각하세요
- 최종 발표 전에 꼭 내용을 검토하고 다듬어야 합니다
- 폰트, 색상, 이미지 위치 등을 손으로 조정하면 더 완성도가 높아집니다

⚠️ **이미지 저작권**

- 사용하는 이미지가 저작권에 문제가 없는지 확인하세요
- 무료 이미지는 Unsplash, Pexels 등에서 구할 수 있습니다

⚠️ **데이터 보안**

- 회사 기밀이나 민감한 정보는 주의해서 사용하세요
- AI 서비스에 업로드된 데이터는 학습에 사용될 수 있습니다

## 흔히 하는 실수

### 실수 1: 폴더 경로에 한글이나 공백 사용

```
❌ 나쁜 예: C:\내 문서\발표 자료\
✅ 좋은 예: C:\Documents\presentation\
```

### 실수 2: 너무 복잡한 프롬프트

```
❌ 나쁜 예: "발표자료 만들어줘"
✅ 좋은 예: "5장짜리 회사 소개 자료 만들어줘. 각 슬라이드 내용은 notes 폴더 참고"
```

### 실수 3: 이미지 파일 형식 문제

- PDF나 특수한 형식 대신 `.jpg`, `.png` 사용
- 파일 크기가 너무 크면 처리가 느려질 수 있으니 적당한 크기로 조정

### 실수 4: Node.js 미설치

- "command not found" 또는 "명령을 찾을 수 없습니다" 에러가 나면
- Node.js가 제대로 설치되었는지 다시 확인하세요
